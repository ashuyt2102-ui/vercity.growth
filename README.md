# Vercity Growth

The Vercity Growth marketing site, built with Next.js, React, and TypeScript. It includes the agency's service pages, founder profiles, contact information, and an interactive animated background.

## Run locally

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validate and run in production

```bash
npm run lint
npm run build
npm run start
```
